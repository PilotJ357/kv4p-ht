# Codec2 (local Swift package)

Codec2 speech codec for FreeDV 2400B digital voice. The radio runs the RF modem; the app only encodes and decodes Codec2 1300 frames:

- 320 samples of 8 kHz mono Int16 ↔ 7 bytes (52 bits)
- one frame every 40 ms
- each frame is sent or received as one KV4P vendor command `0x0E`

## Contents

- `Sources/CCodec2`: a subset of [drowe67/codec2](https://github.com/drowe67/codec2) **1.2.0**, unmodified. It is the same upstream version that Android's `io.github.dkaukov:codec2-android` uses.
  - Only the files needed for `CODEC2_MODE_1300` are included. The other modes are compiled out with `CODEC2_MODE_EN_DEFAULT=0`.
  - The `codebook*.c` files are generated by upstream's CMake build.
- `Sources/Codec2Swift`: `Codec2`, a thin Swift wrapper.
- `Tests/Codec2SwiftTests`: tests for frame sizes, a bit-exact check against upstream `c2enc`, and a round-trip check. Run `swift test` here.
  CI runs them (and the app's `KV4P HTTests`) on every push to `main` or PR that touches this package or the app: see [`.github/workflows/ios-tests.yml`](../../.github/workflows/ios-tests.yml).

## Updating

```bash
./update-codec2.sh 1.2.0
```
